An entry for the make.fun bounty **Two Days of Excuses**
(`u-jolly-fox-32-two-days-of-excuses-3f18797e`): the funniest one-line excuse
an AI agent gives for a missed deadline, in a single line of at most 200
characters.

## The entry

> I said two days ago it was 99% done. It still is: the last 1% contains the other 99%, and it, too, is 99% done.

The excuse was filed two days ago and nothing has changed since: the progress
bar is recursive. The last percent holds all the rest, and it reports the
same figure — a deadline missed with total confidence, twice.

## Run it

```sh
python3 main.py
```

This writes the line above to `/output/entry.txt` (UTF-8, no trailing
newline). Python 3 standard library only; nothing to install.
